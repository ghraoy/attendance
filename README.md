# سجل حضور الماجستير

تطبيق لحفظ حضور وغياب طلبة الماجستير وحساب الساعات، يعمل على الحاسبة والأندرويد وبدون إنترنت.

## التنصيب
- **الحاسبة (Chrome أو Edge):** افتح رابط التطبيق ← زر «تثبيت التطبيق» في أعلى الصفحة، أو أيقونة التثبيت في شريط العنوان.
- **الأندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## طرق الإدخال
1. زر «+ محاضرة»: محاضرة محاضرة.
2. ملف Excel: ورقة لكل مادة، أو جدول بأعمدة التاريخ / المادة / الطالب / الحالة.
3. لصق جدول من Excel أو Google Sheets.
4. صورة ورقة الحضور (تحتاج مفتاح Gemini أو ChatGPT أو Claude).

## البيانات
- تُحفظ على الجهاز نفسه، ومع ربط Google Drive تُرفع تلقائياً إلى مجلد «سجل حضور الماجستير».
- مفاتيح الذكاء الاصطناعي تبقى على الجهاز ولا تُرفع.

## الرفع اليدوي إلى GitHub Pages
1. أنشئ مستودعاً عاماً جديداً على github.com باسم `attendance`.
2. Add file ← Upload files ← اسحب كل محتويات هذا المجلد (مع مجلد icons) ← Commit.
3. Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save.
4. بعد دقيقة يصبح الرابط: `https://<اسم-حسابك>.github.io/attendance/`
