# سجل الحضور الجامعي

تطبيق لحضور وغياب الطلبة لأي قسم ومرحلة: الدراسات الأولية (صباحي / مسائي) والدراسات العليا (دبلوم عالي / ماجستير / دكتوراه).

الرابط: https://ghraoy.github.io/attendance/

## ما يقدمه
- سجلات متعددة: سجل لكل قسم / مرحلة / شعبة / فصل، والتبديل بينها من أعلى الشاشة.
- معالج إنشاء سجل: نوع الدراسة، الجهة، التقويم وأيام الدوام والعطل، قواعد الإنذار، المواد وجدولها الأسبوعي، الطلبة.
- «اليوم»: محاضرات اليوم حسب الجدول وتسجيل الحضور بضغطة (حاضر / غائب / مجاز).
- حساب الساعات المقررة من الجدول والتقويم مع خصم العطل، ونسبة الغياب من مجموع المواد أو لكل مادة، وإنذار أولي وثانٍ وحرمان.
- نموذج Excel موحّد (اقرأني، الإعدادات، العطل، المواد، الطلبة، الحضور، الملخص) بقوائم منسدلة ومعادلات؛ يُستورد ويُصدَّر.
- قراءة صور أوراق الحضور وكتب الإنذار عبر Gemini / ChatGPT / Claude (اختياري).
- مزامنة Google Drive، والعمل بدون إنترنت، والتنصيب على الحاسبة والأندرويد.

## التنصيب
- الحاسبة: افتح الرابط في Chrome أو Edge أو Brave ← «تثبيت التطبيق».
- الأندرويد: افتح الرابط في Chrome ← ⋮ ← «تثبيت التطبيق».
